            Connect Google

            Plume reads (never changes) your Search Console and Analytics data, so agents can see which searches bring visitors and which pages work.

            1. In Google Cloud Console, create an OAuth client of type Desktop app, and turn on the "Google Search Console API", "Google Analytics Data API" and "Google Analytics Admin API".
            2. Add GOOGLE_CLIENT_ID and GOOGLE_CLIENT_SECRET to .env and restart Plume.
